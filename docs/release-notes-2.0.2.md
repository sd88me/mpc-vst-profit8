# Profit-08 2.0.2

## New
- **Name a favourite.** + FAV on BANKS now opens an on-screen keyboard with the program's name (up to 20 characters; SHIFT, DEL, SPACE). SAVE stores the sound under that name, CANCEL stores nothing.
- **RANDOM** on BANKS picks a random program from every loaded bank.
- The page buttons (< PAGE 1/3 >) moved into the Programs panel's header, far right, to make room.

## Compatibility
- Same sound engine, parameters and project format as 2.0.1: the new keys and keyboard are added after the existing parameters, so programs, favourites and projects load unchanged.

## Tested
Offline: the host test (keyboard, RANDOM, favourites, project chunks) and the host simulator. On an MPC Live III with a beta build of this code: the keyboard, RANDOM and the new BANKS layout. The release zips were not installed.
